# Project Overview

This project focuses on predictive analysis using machine learning techniques to predict whether a patient is diabetic based on medical parameters. The project was developed using Python and various machine learning libraries in Jupyter Notebook.

The primary objective of this project is to build a classification model capable of predicting diabetes using patient medical data such as glucose level, BMI, blood pressure, insulin level, age, pregnancies, and other medical features.

Machine learning is a branch of Artificial Intelligence that enables systems to learn patterns from historical data and make intelligent predictions without being explicitly programmed. In this project, supervised learning techniques were applied to train classification models using a diabetes dataset.

# Dataset Description

The project uses the Pima Indians Diabetes Dataset. The dataset contains several medical predictor variables and one target variable called Outcome.

Features include:

- Pregnancies
- Glucose
- Blood Pressure
- Skin Thickness
- Insulin
- BMI
- Diabetes Pedigree Function
- Age

Target Variable:
- Outcome
  - 0 → Non-Diabetic
  - 1 → Diabetic

# Project Workflow

## 1. Data Collection

The diabetes dataset was downloaded and loaded into Jupyter Notebook using Pandas.

## 2. Data Preprocessing

Data preprocessing was performed to clean and prepare the dataset for machine learning.

The following preprocessing techniques were applied:
- Checking missing values
- Handling invalid zero values
- Removing duplicate entries
- Feature scaling using StandardScaler

Data preprocessing improves model performance and ensures better learning.

# Machine Learning Models Used

## Logistic Regression

Logistic Regression was initially used as the baseline classification model. It predicts categorical outcomes and works effectively for binary classification problems.

## Random Forest Classifier

Random Forest was implemented to improve prediction accuracy. It combines multiple decision trees and produces better generalization.

## XGBoost Classifier

XGBoost was also applied for advanced prediction performance and better accuracy optimization.
